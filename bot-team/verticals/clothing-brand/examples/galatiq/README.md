# Worked example 2: Galatiq (cold run, end to end)

The clothing team run on a business it had never seen, the hackathon host, from public pages only.

1. **Brand discovery**: read galatiq.ai (copy, CSS colors, share image) and wrote `../galatiq.brand-profile.json`, with a source for every fact. Green and black come from Galatiq's own site, not from No Thought.
2. **Design**: `merch-collection.jpg` (hoodie, tee, cap, stickers) and `hoodie-back.jpg`. These are generated concepts.
3. **Vendor Scout**: `vendor-compare.md`, real Austin and online vendors with links.
4. **Outreach**: `rfq-draft.md`, a quote request that uses an online price to negotiate. DRAFT, never sent.
5. **Ops**: `purchase-order-draft.md`, about $1,610 total with a $482.85 deposit in Stripe test mode. Labeled **Over $500, needs Logan**.

Founder rule shown: nothing is sent, ordered or charged without the founder's OK.
