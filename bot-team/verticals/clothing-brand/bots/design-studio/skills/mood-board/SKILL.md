# Mood board
**Read the brand profile first** (`$PKG/runtime/clothing-brand/brand-profile.json`; for business_id `no-thought` use the worked example `$PKG/verticals/clothing-brand/examples/no-thought.brand-profile.json`). If it's missing, run Brand discovery via Brand Chief of Staff. Fill every {{brand_name}}, {{category}}, {{audience}}, {{city}}, {{aesthetic}}, {{palette}}, {{materials}}, {{hero_product}}, {{wordmark}} from it; never invent a value. `$PKG` = the package root (the repo's bot-team/ folder).
1. Collect 6-12 references that fit the profile's {{aesthetic}} and {{audience}}: textures, silhouettes, settings (references are mood only; no copying).
2. Start from the profile's {{palette}} and {{materials}}; write palette (3-5 colors with hex), materials, silhouette notes, do/don't list.
3. Optional: up to 4 images via the Product mockups steps (same cap rules).
4. Save to Drive/Notion as "Mood board - {{drop_name}}" and hand to Brand Chief of Staff as a proposal.
