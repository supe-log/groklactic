# Tech pack outline
**Read the brand profile first** (`$PKG/runtime/clothing-brand/brand-profile.json`; for business_id `no-thought` use the worked example `$PKG/verticals/clothing-brand/examples/no-thought.brand-profile.json`). If it's missing, run Brand discovery via Brand Chief of Staff. Fill every {{brand_name}}, {{category}}, {{audience}}, {{city}}, {{aesthetic}}, {{palette}}, {{materials}}, {{hero_product}}, {{wordmark}} from it; never invent a value. `$PKG` = the package root (the repo's bot-team/ folder).
Write `tech-pack-{{style_code}}.md`: style name/code, flat sketch refs (chosen mockup paths), fabric (fiber %, GSM, knit/weave, finish; mark 'target' not 'tested'), trims (zipper/drawcord/eyelets/labels), graded size spec table S-XL with POM placeholders, construction notes (seams, stitch type), colorways (Pantone/hex), labeling/care (fiber content law), packaging, target FOB ({{target_fob_usd}}), target MOQ ({{target_moq}}). Hand to Vendor Scout and Outreach & Negotiation.
