# bot-team

This repo has one purpose: **Dolce & Grokbana**, the Grok Bot that builds and runs a company's merch team.

- `merch-team-setup/`: the bot itself (setup skill, template, machine-readable spec, architecture).
- `verticals/clothing-brand/`: reference plan and the Galatiq worked example.
- `fallback/`, `clothing/`: demo stills and mockups.
- `config/higgsfield-tools.json`: the Higgsfield tools the mockup step uses.
- `demo.md`: the 3-minute judge demo.

Start at [merch-team-setup/README.md](merch-team-setup/README.md).
